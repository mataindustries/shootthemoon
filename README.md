# Shoot the Moon — Moon Core

Moon Core is the true-3D technical prototype for Shoot the Moon. This repository
currently contains planning documents and a verified Vite, React, strict
TypeScript, and React Three Fiber scaffold. It intentionally does not implement
the Moon or any gameplay yet.

Start with [PLAN.md](./PLAN.md), [ARCHITECTURE.md](./ARCHITECTURE.md), and
[PERFORMANCE_BUDGET.md](./PERFORMANCE_BUDGET.md).

## Local commands

    npm ci
    npm run dev
    npm run check
    npm run build
    npm run preview

Node.js 20.19 or newer supported release lines are required; see package.json
for the exact engine range.
